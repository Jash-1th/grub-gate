Prompt Guide for Building the Grub-Gate Frontend (JavaScript Edition)
Follow these prompts sequentially to build the project foundation and the complete, SSR-aware homepage for Grub-Gate using React and plain JavaScript.

Prompt 1: Project Initialization & Setup

"Initialize a new project for 'Grub-Gate'. Create a root directory with two sub-directories: frontend and backend.

Inside the frontend directory, perform the following setup:

Scaffold a new React + JavaScript application using Vite.

Install and configure Tailwind CSS for styling.

Install the necessary dependencies for the server and routing: express and react-router-dom.

Create a new directory at frontend/src/assets/images."

Prompt 2: SSR Foundation Setup

"Now, configure the Vite project in the frontend directory to support SSR for production while using CSR for development. Use JavaScript files (.js, .jsx).

Create a server.js file in the frontend root directory with an Express server setup to handle server-side rendering.

Create a server entry point at frontend/src/main.ssr.jsx which uses ReactDOMServer.renderToString and StaticRouter.

Modify the client entry point at frontend/src/main.jsx to use ReactDOM.hydrateRoot and BrowserRouter.

Update frontend/index.html to include the <!--ssr-outlet--> placeholder inside the root div.

Create a vite.config.js file and configure it to handle both client and SSR builds.

Update the scripts in frontend/package.json to include commands for dev, build, build:client, build:server, and start to orchestrate the entire process."

Prompt 3: Core App Structure & Routing

"Set up the basic application structure and routing within the frontend/src directory.

Create two new folders: pages and components.

Inside src/pages, create a file for our homepage: HomePage.jsx.

Inside src/components, create three sub-folders: layout, common, and home.

Update src/App.jsx to use react-router-dom. It should define a single route for / that renders the HomePage component. Also, render placeholder Header and Footer components that we will create next."
